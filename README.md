The launch button already points to the deployed Google Apps Script web app.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md`, and `.nojekyll` to the root of the `user` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Click **Save**.

Once GitHub finishes publishing, your site should be available at:

`https://dndfriends.github.io/user/`
